# concert-ticketing-analysis
## 📌 Project Overview
An end-to-end data analysis project focusing on analyzing fan sentiments, complaints, and reactions regarding concert ticketing issues and organization.

## 🎯 Key Insights
- **Pre-booking & Organization Dissatisfaction (استياء من الحجز المسبق والتنظيم):** Represented the highest volume of feedback (220 comments).
- **Secondary Market & Scalping (عرض واستغلال السوق السوداء):** Major area of fan concern along with technical server glitches.
- **Positive Ticket Success (نجاح بالحجز وحماس):** Represented a smaller proportion of overall sentiment.

## 🛠️ Tools & Technologies Used
- **Power BI:** Data Visualization, Dashboard Styling, DAX Measures.
- **Python:** Data Cleaning and Sentiment Processing.
